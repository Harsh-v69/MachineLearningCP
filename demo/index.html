What is this, and how do I read it?

You pick a puzzle family and some parameters, click Generate, and this page builds a brand-new, never-seen-before puzzle instance right there in your browser (nothing below is pre-solved or hardcoded). An independent breadth-first search then quietly works out the true shortest solution length, T*, so you have a ground truth to compare against.

Then you pick a solver (the search algorithm) and an agent (how it behaves under simulated mistakes) and click Run episode. The board turns into a step-by-step playback: use the transport controls or drag the scrubber to walk through exactly what the agent planned, executed, and (if it slipped) replanned, one step at a time.

Everything you see solving is a real graph search, not a canned animation — change any parameter and generate again to get a different instance.

BFS explores evenly and is always exactly shortest, but slowest. A* uses a distance estimate to search far fewer nodes, still exactly shortest. Weighted A* is faster still but may return a slightly longer plan. IDA* behaves like A* with a fraction of the memory.
